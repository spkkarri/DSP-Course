Understanding Nyquist and Aliasing

The Nyquist-Shannon Sampling Theorem states that to reconstruct a continuous band-limited signal perfectly from its samples, the sampling frequency \(f_s\) must be strictly greater than twice the highest frequency component \(f_{max}\) present in the signal:

\[f_s > 2 f_{max}\]

What is Aliasing? When \(f_s \le 2 f_{max}\) (under-sampling), the frequency components above \(f_s/2\) overlap into the primary band. During reconstruction, these high-frequency components masquerade (alias) as lower frequencies, making it impossible to separate them from the original low-frequency signal components.

Role of the Anti-Aliasing Filter (AAF): In practical systems, signals often contain high-frequency noise or unwanted components. The AAF is an analog low-pass filter applied before sampling. It cuts off all frequencies higher than \(f_s / 2\). Try disabling the AAF in the simulator while keeping the sampling rate low; you will observe the reconstructed waveform (red curve) distorting due to the un-attenuated high-frequency component folding back into the low-frequency region.

Periodicity in Discrete-Time (DT) vs. Continuous-Time (CT)

A continuous-time sinusoid \(x(t) = \cos(\Omega_0 t)\) is always periodic for any non-zero value of \(\Omega_0\). Its period is \(T = 2\pi / \Omega_0\).

In contrast, a discrete-time sinusoid \(x[n] = \cos(\omega_0 n)\) is periodic only if its frequency \(\omega_0\) is a rational multiple of \(2\pi\). This implies there exists an integer \(N > 0\) such that:

\[\frac{\omega_0}{2\pi} = \frac{m}{N} \quad \text{where } m, N \in \mathbb{Z}^+\]

Here, \(N\) represents the fundamental period (in number of samples), and \(m\) represents the number of cycles completed in the continuous wave over those \(N\) samples. If this ratio is an irrational number (like \(1 / 3\pi\) or \(0.15412...\)), the signal will never repeat identical values at integer index points, making it aperiodic. Use the slider above to dial in irrational-like decimal values; you will see the periodicity disappear as the signal pattern never repeats exactly.

Signal Symmetry: Even & Odd Decomposition

Any discrete-time signal \(x[n]\) can be uniquely decomposed into a sum of an Even Component \(x_e[n]\) and an Odd Component \(x_o[n]\), such that: \[x[n] = x_e[n] + x_o[n]\] where \(x_e[-n] = x_e[n]\) (symmetric about the vertical axis) and \(x_o[-n] = -x_o[n]\) (anti-symmetric about the origin, which implies \(x_o[0] = 0\)). These are computed as: \[x_e[n] = \frac{x[n] + x[-n]}{2}, \quad x_o[n] = \frac{x[n] - x[-n]}{2}\]

Properties & Operations on Signals

Discrete-time signals can be manipulated using several basic operations. These operations are essential for understanding how filters and DSP systems process signals:

1. Time Shifting

A signal \(x[n]\) is shifted in time by replacing the independent variable \(n\) with \(n - n_0\), where \(n_0\) is an integer: \[y[n] = x[n - n_0]\] If \(n_0 > 0\), the signal is **delayed** (shifted to the right). If \(n_0 < 0\), the signal is **advanced** (shifted to the left).

2. Time Reversal (Folding)

Time reversal reflects the signal about the origin \(n = 0\): \[y[n] = x[-n]\] (We saw this visually in the Even & Odd decomposition simulator above!)

3. Time Scaling (Decimation & Interpolation)

Time scaling alters the sampling rate. * **Decimation (Downsampling)** by an integer factor \(D\) retains only every \(D\)-th sample: \[y[n] = x[D \cdot n]\] * **Interpolation (Upsampling)** by an integer factor \(I\) inserts \(I-1\) zeros between adjacent samples: \[y[n] = \begin{cases} x[n/I], & n = 0, \pm I, \pm 2I, \dots \\ 0, & \text{otherwise} \end{cases}\]

4. Arithmetic Operations

Signals can be combined point-by-point: * **Addition:** \(y[n] = x_1[n] + x_2[n]\) (used in mixers and summing amplifiers) * **Multiplication:** \(y[n] = x_1[n] \cdot x_2[n]\) (used in modulation and windowing) * **Amplitude Scaling:** \(y[n] = A \cdot x[n]\) (amplification or attenuation)

What is a DSP System?

A **system** is mathematically defined as a transformation or mapping operator \(\mathcal{T}\) that operates on an input sequence (excitation) \(x[n]\) to produce an output sequence (response) \(y[n]\):

\[y[n] = \mathcal{T}\{x[n]\}\]

In a DSP context, the "processor" is the physical implementation of this system. Rather than working with continuous physical circuits, the system is defined by mathematical algorithms. For example, a simple digital filter system can be described by a **difference equation** or a **convolution sum** (which we will explore in Lecture 2).

Fundamental System Classifications

To analyze DSP systems, we evaluate them against these core mathematical properties:

  • Linearity: A system is linear if it satisfies the principles of superposition (additivity) and homogeneity (scaling): \[\mathcal{T}\{a \cdot x_1[n] + b \cdot x_2[n]\} = a \cdot \mathcal{T}\{x_1[n]\} + b \cdot \mathcal{T}\{x_2[n]\}\]
  • Time-Invariance: A system is time-invariant if a shift in the input causes an identical shift in the output: \[\text{If } y[n] = \mathcal{T}\{x[n]\}, \text{ then } y[n-n_0] = \mathcal{T}\{x[n-n_0]\}\]
  • Causality: A system is causal if the output at index \(n_0\) depends only on present and past inputs (\(x[n]\) for \(n \le n_0\)), not on future inputs.
  • Stability (BIBO): A system is Bounded-Input Bounded-Output stable if every bounded input (\(|x[n]| \le M_x < \infty\)) produces a bounded output (\(|y[n]| \le M_y < \infty\)).

Checkpoint 1: Why is an analog anti-aliasing filter necessary before the ADC, rather than just using a digital filter after?
Once sampling occurs, any frequency component higher than \(f_s / 2\) has already folded back (aliased) into the low-frequency band. At that point, the aliased component is indistinguishable from the actual signal. A digital filter operates on the already corrupted sampled data and cannot separate the alias from the true signal. The fundamental period \(N\) is the denominator of the simplified fraction: \[N = 50 \text{ samples}\] This means the signal completes exactly \(m = 3\) cycles of the underlying continuous sinusoid over \(N = 50\) samples.
Checkpoint 3: Is the discrete-time sequence \(x[n] = \cos(2n)\) periodic? Explain.

Therefore, there is no integer \(N\) that can satisfy the periodic condition \(x[n+N]=x[n]\). The signal \(x[n] = \cos(2n)\) is **aperiodic**.

Core Theory: LTI Systems & Convolution
A Linear Time-Invariant (LTI) system is uniquely and completely characterized by its impulse response \(h[n]\). The output of an LTI system to any input \(x[n]\) can be found using the convolution sum.
Convolution Sum \[y[n] = \sum_{k=-\infty}^{\infty} x[k] h[n-k] = x[n] * h[n]\]

To calculate convolution graphically or analytically for each index \(n\), you follow four steps: 1. Folding (Time Reversal), 2. Shifting, 3. Multiplication, and 4. Summation.

Commutativity \[x[n] * h[n] = h[n] * x[n]\]

The order of signals in convolution does not affect the output. This is proven by substituting a new variable \(m = n - k\) (which means \(k = n - m\)) into the convolution sum.

BIBO Stability \[\sum_{n=-\infty}^{\infty} |h[n]| < \infty\]

A system is Bounded-Input Bounded-Output (BIBO) stable if every bounded input produces a bounded output. For an LTI system, this requires the impulse response to be absolutely summable.

Step Response \[s[n] = \sum_{k=-\infty}^{n} h[k] \quad \text{and} \quad h[n] = s[n] - s[n-1]\]

The step response \(s[n]\) is the system's response to the unit step input \(u[n]\). The impulse response can be recovered from the step response by taking its first difference.

Concept Formula Notes
Convolution Sum \(y[n] = x[n] * h[n]\) Fundamental LTI operation
Causality \(h[n] = 0 \\; \forall n < 0\) Depends only on past/present inputs
Associativity \((x * h_1) * h_2 = x * (h_1 * h_2)\) Series cascade equivalent
Distributivity \(x * (h_1 + h_2) = x * h_1 + x * h_2\) Parallel equivalent

▶ Q1: An LTI system has impulse response \(h[n] = (1.2)^n u[n]\). Is the system BIBO stable?

Check absolute sum: \[\sum_{n=-\infty}^{\infty} |h[n]| = \sum_{n=0}^{\infty} (1.2)^n\] Since the base \(|1.2| \ge 1\), this geometric series diverges to \(\infty\). The system is unstable (its impulse response grows exponentially).

▶ Q2: Find the homogeneous solution of the difference equation \(y[n] - 0.5 y[n-1] = x[n]\).
  1. Set \(x[n] = 0 \Rightarrow y[n] - 0.5 y[n-1] = 0\).
  2. Assume \(y_h[n] = C \lambda^n \Rightarrow C \lambda^n - 0.5 C \lambda^{n-1} = 0 \Rightarrow \lambda - 0.5 = 0 \Rightarrow \lambda = 0.5\).
  3. Thus, the homogeneous solution is: \[y_h[n] = C (0.5)^n\]

Checkpoint 3: Explain the difference between FIR and IIR filters in terms of their difference equations and feedback.
A **Finite Impulse Response (FIR)** system does not use feedback. Its difference equation has only feed-forward terms: \[y[n] = \sum_{k=0}^{M} b_k x[n-k]\] Consequently, the impulse response has a finite duration of exactly \(M+1\) samples. It is always stable.

An **Infinite Impulse Response (IIR)** system utilizes feedback. Its difference equation contains past output values (feedback terms): \[y[n] = -\sum_{k=1}^N a_k y[n-k] + \sum_{k=0}^M b_k x[n-k]\] Due to the feedback, the impulse response theoretically continues indefinitely. It can become unstable if the feedback gains are too high.

Core Theory: DTFT & Frequency Domain
The Discrete-Time Fourier Transform (DTFT) maps a discrete-time sequence into a continuous, periodic complex frequency function. It represents the limit of the DFT as the number of samples approaches infinity, providing a continuous spectrum for discrete signals.

Forward DTFT (Analysis Equation)

\[ X(e^{j\omega}) = \sum_{n=-\infty}^{\infty} x[n] e^{-j\omega n} \]

The DTFT is always periodic in digital frequency \(\omega\) with a period of \(2\pi\) due to the periodicity of the complex exponential.

Inverse DTFT (Synthesis Equation)

\[ x[n] = \frac{1}{2\pi} \int_{-\pi}^{\pi} X(e^{j\omega}) e^{j\omega n} d\omega \]

This equation reconstructs the original discrete sequence from its continuous frequency spectrum by integrating over a single \(2\pi\) period.

DTFT of a Rectangular Pulse

For a pulse of length \(M\) (where \(x[n]=1\) for \(0 \le n \le M-1\)):

  1. Use the finite geometric series: \( X(e^{j\omega}) = \sum_{n=0}^{M-1} e^{-j\omega n} = \frac{1 - e^{-j\omega M}}{1 - e^{-j\omega}} \)
  2. Factor out half-angles: \( X(e^{j\omega}) = \frac{e^{-j\omega M/2} ( e^{j\omega M/2} - e^{-j\omega M/2} )}{e^{-j\omega/2} ( e^{j\omega/2} - e^{-j\omega/2} )} \)
  3. Simplify to the Dirichlet kernel: \( X(e^{j\omega}) = e^{-j\omega(M-1)/2} \frac{\sin(\omega M/2)}{\sin(\omega/2)} \)

Parseval's Theorem

\[ \sum_{n=-\infty}^{\infty} |x[n]|^2 = \frac{1}{2\pi} \int_{-\pi}^{\pi} |X(e^{j\omega})|^2 d\omega \]

This Energy Conservation relation proves that the total energy computed in the time domain equals the total energy in the frequency domain.

Convergence & Existence of DTFT

For any infinite sequence, the summation defining the DTFT may not always converge to a finite limit. The **existence** of the DTFT is guaranteed if the signal is **absolutely summable**: \[\sum_{n=-\infty}^{\infty} |x[n]| < \infty\] * **Stable Systems**: If an LTI system is BIBO stable, its impulse response \(h[n]\) is absolutely summable, meaning its frequency response \(H(e^{j\omega}) = \text{DTFT}\{h[n]\}\) is guaranteed to exist. * **Marginal Convergence**: Signals that are not absolutely summable but are square-summable (like the sinc function \(\frac{\sin(\omega_c n)}{\pi n}\)) converge in the mean-square sense, but exhibit oscillations (Gibbs phenomenon) at points of discontinuity.

A complex exponential \(e^{j(\omega n + \phi)}\) represents a point rotating on a circle of radius \(A\) in the complex plane. * **Frequency (Speed)** determines how fast the point rotates around the circle. Every complex signal is simply a weighted sum of these rotating phasor circles!

Checkpoint 1: Why is the DTFT \(X(e^{j\omega})\) always periodic with period \(2\pi\), whereas continuous-time Fourier transforms are not periodic?
Because discrete-time complex exponentials are periodic in frequency. If we evaluate the frequency at \(\omega + 2\pi\): \[e^{-j(\omega+2\pi)n} = e^{-j\omega n} \cdot e^{-j 2\pi n}\] Since \(n\) is strictly an integer, \(e^{-j 2\pi n} = 1\), making \(e^{-j(\omega+2\pi)n} = e^{-j\omega n}\). Continuous-time exponentials can take any real value of time \(t\) rather than integer steps, so \(e^{-j 2\pi t}\) is not equal to 1, meaning the continuous spectrum does not repeat.
Checkpoint 2: Find the DTFT of the shifted unit impulse sequence \(x[n] = \delta[n - n_0]\).
Using the DTFT analysis equation: \[X(e^{j\omega}) = \sum_{n=-\infty}^{\infty} \delta[n - n_0] e^{-j\omega n}\] Due to the sifting property of the impulse, the only non-zero term is at \(n = n_0\). Replacing \(n\) with \(n_0\) yields: \[X(e^{j\omega}) = e^{-j\omega n_0}\] This corresponds to a magnitude of \(|X(e^{j\omega})| = |e^{-j\omega n_0}| = 1\) (all frequencies are flat/equal) and a phase of \(\angle X(e^{j\omega}) = -n_0 \omega\) (a linear ramp proportional to the delay).
Checkpoint 3: Explain the physical meaning of the Convolution Property in filters.
The Convolution Property states that: \[\text{DTFT}\{x[n] * h[n]\} = X(e^{j\omega}) \cdot H(e^{j\omega})\] In the time domain, a filter processes input samples by taking a weighted sum (convolution). In the frequency domain, this corresponds to multiplying the input signal's spectrum by the filter's frequency response. This makes it simple to understand filter design: to remove high frequencies, we select a filter whose frequency response \(H(e^{j\omega})\) is zero at high frequencies, which multiplies those components by zero, filtering them out of the output.

Core Theory: Frequency Response & Group Delay
In linear system analysis, complex exponentials are eigenfunctions of LTI systems. The frequency response \(H(e^{j\omega})\) represents the complex eigenvalue that scales an input complex exponential, detailing how the system affects magnitude and phase.
Eigenfunction Property

An LTI system output for a complex exponential input is scaled by the frequency response:

\[y[n] = H(e^{j\omega}) e^{j\omega n}\]

where \(H(e^{j\omega}) = \sum_{k=-\infty}^{\infty} h[k] e^{-j\omega k}\).

Magnitude & Phase

The complex frequency response can be split into magnitude and phase components:

\[H(e^{j\omega}) = \left| H(e^{j\omega}) \right| e^{j \theta(\omega)}\]

where the magnitude is the gain, and the phase \(\theta(\omega) = \angle H(e^{j\omega})\) is the shift.

Phase Delay vs. Group Delay

Different frequency components experience different delays in multi-frequency signals:

  • Phase Delay (delay of carrier): \[\tau_p(\omega) = -\frac{\angle H(e^{j\omega})}{\omega}\]
  • Group Delay (delay of envelope): \[\tau_g(\omega) = -\frac{d\angle H(e^{j\omega})}{d\omega}\]
First-Order Filter Group Delay Derivation

For a filter \(y[n] - r y[n-1] = x[n]\) with \(|r| < 1\):

  1. Frequency Response: \[H(e^{j\omega}) = \frac{1}{1 - r e^{-j\omega}}\]
  2. Phase Response: \[\theta(\omega) = -\arctan\left( \frac{r\sin\omega}{1 - r\cos\omega} \right)\]
  3. Group Delay: Differentiating \(\theta(\omega)\) yields: \[\tau_g(\omega) = \frac{r\cos\omega - r^2}{1 + r^2 - 2r\cos\omega}\]

Eigenfunctions & Phase Distortion

* **Eigenfunctions**: A function is an eigenfunction of an operator if applying the operator simply scales the function by a scalar factor. Since discrete-time complex exponentials \(e^{j\omega n}\) are eigenfunctions of LTI systems, they are fundamental in frequency-domain analysis. The scaling eigenvalue is the **Frequency Response** \(H(e^{j\omega})\). * **Phase Distortion**: If different frequencies are delayed by different amounts, the shapes of the carrier signals disperse, leading to symbol interference in data transmission or phase coloration in audio. A **linear phase** filter ensures that the group delay is constant, meaning it introduces only pure delay without distortion.

Core Theory: Z-Transform & ROC
The Z-transform generalizes the DTFT by replacing the complex frequency \(e^{j\omega}\) with a general complex variable \(z = re^{j\omega}\). The set of all values of \(z\) for which the sum converges is defined as the Region of Convergence (ROC).
Bilateral Z-Transform Definition \[X(z) = \sum_{n=-\infty}^{\infty} x[n] z^{-n}\] It represents the DTFT of the sequence \(x[n]\) weighted by the exponential factor \(r^{-n}\). When evaluated on the unit circle (\(r=1\)), it reduces exactly to the DTFT.
Right-Sided (Causal) Signal ROC \[|z| > r_{max}\] For causal sequences where \(x[n] = 0\) for \(n < 0\), the ROC extends outward from the outermost pole to infinity. A causal LTI system is BIBO stable if and only if all poles lie strictly inside the unit circle.
Time Shift Property \[x[n-n_0] \longleftrightarrow z^{-n_0} X(z)\] Proof:
  1. Definition: \(Z\{x[n-n_0]\} = \sum_{n=-\infty}^{\infty} x[n-n_0] z^{-n}\)
  2. Let \(m = n - n_0 \implies n = m + n_0\):
  3. \(\sum_{m=-\infty}^{\infty} x[m] z^{-(m+n_0)} = z^{-n_0} \sum_{m=-\infty}^{\infty} x[m] z^{-m} = z^{-n_0} X(z)\)
In DSP block diagrams, multiplying by \(z^{-1}\) represents a unit-sample delay element.
Initial Value Theorem \[x[0] = \lim_{z \to \infty} X(z)\] If \(x[n]\) is a causal sequence, as \(z \to \infty\), all terms with \(z^{-k}\) for \(k \ge 1\) approach 0, leaving only \(x[0]\).

Understanding ROC Convergence Boundaries

* **Pole Bounds**: The boundary of the ROC is always circular and passes through a pole. It cannot expand beyond a pole because the value of the summation diverges to infinity at that location. * **Right-Sided (Causal) Signals**: Summation is \(\sum_{n=0}^{\infty} x[n] z^{-n}\). Since powers of \(z^{-1}\) decay as radius increases, convergence occurs in the outer region: \(|z| > |p_{max}|\). * **Left-Sided (Anti-Causal) Signals**: Summation is \(\sum_{n=-\infty}^{-1} x[n] z^{-n} = \sum_{m=1}^{\infty} x[-m] z^m\). Since powers of \(z\) decay as radius decreases toward the origin, convergence occurs in the inner region: \(|z| < |p_{min}|\).

Core Theory: Inverse Z-Transform
The Z-transform maps a sequence \(x[n]\) to \(X(z)\). However, the inverse Z-transform is not unique without specifying the Region of Convergence (ROC). The same algebraic expression \(X(z)\) can correspond to different discrete sequences depending on whether the ROC represents a causal or anti-causal system.
Partial Fraction Expansion (Distinct Poles) \[ \frac{X(z)}{z} = \frac{A_1}{z-p_1} + \frac{A_2}{z-p_2} + \dots + \frac{A_N}{z-p_N} \] For a rational system function with distinct poles, we expand \(X(z)/z\) into simpler fractions. The residue \(A_k\) for each pole \(p_k\) is found using the cover-up method: \[ A_k = \left[ (z - p_k) \frac{X(z)}{z} \right]_{z = p_k} \]
Repeated Poles If \(X(z)/z\) contains a pole \(p_1\) repeated \(m\) times, the coefficients for the repeated poles are computed using derivatives. The formula for the \(k\)-th coefficient is: \[ A_{1k} = \frac{1}{(m-k)!} \left[ \frac{d^{m-k}}{dz^{m-k}} \left( (z - p_1)^m \frac{X(z)}{z} \right) \right]_{z = p_1} \]
Power Series Expansion (Long Division) This method expands \(X(z)\) directly into a power series where coefficients of \(z^{-n}\) are the time samples \(x[n]\). For a causal sequence, arrange polynomials in descending powers of \(z\) to get \(x[0] + x[1]z^{-1} + \dots\). For an anti-causal sequence, arrange in ascending powers of \(z\) to get \(x[-1]z^1 + x[-2]z^2 + \dots\).
Contour Integration (Residue Method) The formal definition of the inverse Z-transform uses a contour integral in the complex plane along a closed path \(C\) in the ROC: \[ x[n] = \frac{1}{2\pi j} \oint_{C} X(z) z^{n-1} dz \] Using Cauchy's Residue Theorem, this evaluates to the sum of residues of \(X(z) z^{n-1}\) at the poles inside the contour.
Stability & Causality A causal LTI system (ROC \(|z| > p_{max}\)) is BIBO stable if and only if the ROC contains the unit circle (\(|z| = 1\)). This means all poles must lie strictly inside the unit circle: \[ |p_i| < 1 \quad \forall i \]

Core Theory: DFT & Matrix Formulation
The Discrete Fourier Transform (DFT) evaluates the continuous-frequency DTFT at N uniform samples on the unit circle. This allows us to represent a discrete-time signal of finite length as a finite sequence of discrete frequency bins, making frequency analysis computable.
DFT Definition \[X[k] = \sum_{n=0}^{N-1} x[n] W_N^{kn}, \quad 0 \le k \le N-1\] where the twiddle factor is \(W_N = e^{-j\frac{2\pi}{N}}\).
IDFT Definition \[x[n] = \frac{1}{N} \sum_{k=0}^{N-1} X[k] W_N^{-kn}, \quad 0 \le n \le N-1\] This formula reconstructs the original time-domain sequence from its frequency bins.
IDFT Derivation from Orthogonality \[\sum_{n=0}^{N-1} W_N^{kn} W_N^{-ln} = N \delta[k-l]\]
  1. The summation is a geometric series with common ratio \(r = W_N^{k-l}\).
  2. If \(k = l\), \(r = 1\) and the sum evaluates to \(N\).
  3. If \(k \neq l\), \(r \neq 1\) and the sum evaluates to 0.
Matrix Formulation \[\mathbf{X} = \mathbf{W}_N \mathbf{x}\] The DFT can be expressed as a linear transformation using the \(N \times N\) DFT matrix \(\mathbf{W}_N\), where the element at row \(k\) and column \(n\) is \(\mathbf{W}_N[k, n] = W_N^{kn}\).
Twiddle Factor Properties \[W_N^{kN} = 1, \quad W_N^{k+N} = W_N^k\] The twiddle factor exhibits periodicity and conjugate symmetry (\(W_N^{k(N-n)} = (W_N^{kn})^*\)), which are crucial for fast algorithms like the FFT.

Circular Convolution \(X_1[k] X_2[k]\) Product of DFTs corresponds to circular convolution
Parseval's Theorem \(\sum |x[n]|^2 = \frac{1}{N} \sum |X[k]|^2\) Energy conservation between domains
Conjugate Symmetry \(X[k] = X^*[-k \pmod N]\) For real-valued time sequences

Checkpoint 1: Why is the DFT of a real-valued signal symmetric? (conjugate symmetry)
For any real sequence \(x[n] = x^*[n]\), the DFT satisfies: \[X[N-k] = X^*[k]\] This is because: \[X[N-k] = \sum_{n=0}^{N-1} x[n] e^{-j \frac{2\pi}{N} (N-k) n} = \sum_{n=0}^{N-1} x[n] e^{-j 2\pi n} e^{j \frac{2\pi}{N} k n} = \sum_{n=0}^{N-1} x[n] e^{j \frac{2\pi}{N} k n}\] Since \(x[n]\) is real, this is exactly the complex conjugate of \(X[k]\). This symmetry implies that the magnitude spectrum is symmetric: \(|X[N-k]| = |X[k]|\) and the phase is anti-symmetric: \(\angle X[N-k] = -\angle X[k]\). You can verify this symmetry on the simulator for any real signal preset.
Checkpoint 2: Explain the orthogonality of the DFT matrix columns.
The DFT matrix \(\mathbf{W}_N\) has columns \(\mathbf{w}_m\) corresponding to basis sequences. Two columns \(\mathbf{w}_a\) and \(\mathbf{w}_b\) are orthogonal, meaning: \[\langle \mathbf{w}_a, \mathbf{w}_b \rangle = \sum_{n=0}^{N-1} W_N^{a n} (W_N^{b n})^* = \sum_{n=0}^{N-1} e^{-j\frac{2\pi}{N}(a - b)n} = \begin{cases} N & \text{if } a \equiv b \pmod N \\ 0 & \text{otherwise} \end{cases}\] This property allows the inverse DFT matrix to be calculated simply as \(\frac{1}{N}\mathbf{W}_N^H\), removing the need for computationally heavy matrix inversions.

Core Theory: Circular Convolution & DFT Properties
A fundamental consequence of discrete frequency sampling is that the corresponding time sequence is treated as periodic. Because of this, standard operations like shifting and convolution become circular. Circular convolution in time is equivalent to pointwise multiplication in frequency.
Circular Convolution Definition \[ y[n] = x_1[n] \circledast_N x_2[n] = \sum_{m=0}^{N-1} x_1[m] x_2[((n - m))_N] \] The modulo indexing \(((n-m))_N\) means that if the index goes out of the range \([0, N-1]\), it wraps around. This circular behavior fundamentally alters how the sequences overlap compared to linear convolution.
Circular Convolution Theorem Proof \[ \text{DFT}\{x_1[n] \circledast_N x_2[n]\} = X_1[k] \cdot X_2[k] \]
  1. Start with the DFT of the circular convolution: \( Y[k] = \sum_{n=0}^{N-1} \left[ \sum_{m=0}^{N-1} x_1[m] x_2[((n - m))_N] \right] W_N^{kn} \)
  2. Interchange the order of summation: \( Y[k] = \sum_{m=0}^{N-1} x_1[m] \left[ \sum_{n=0}^{N-1} x_2[((n - m))_N] W_N^{kn} \right] \)
  3. The inner sum is the DFT of a circularly shifted sequence, giving \( X_2[k] W_N^{km} \)
  4. Substitute back: \( Y[k] = X_2[k] \sum_{m=0}^{N-1} x_1[m] W_N^{km} \) which simplifies to \( X_1[k] \cdot X_2[k] \).
Linear vs Circular Convolution \[ y_{circ}[n] = \sum_{r=-\infty}^{\infty} y_{lin}[n - rN] \] If we perform an \(N\)-point circular convolution, it suffers from time-domain aliasing if \(N\) is too small. To make circular convolution equivalent to linear convolution, we must zero-pad the sequences such that \(N \ge L_1 + L_2 - 1\).
Hermitian (Conjugate) Symmetry \[ X[k] = X^*[N-k] \] For a purely real signal \(x[n]\), the DFT is conjugate symmetric.
  1. Take conjugate of DFT definition: \( X^*[k] = \sum_{n=0}^{N-1} x^*[n] e^{j \frac{2\pi}{N} kn} \)
  2. Since \( x[n] \) is real, \( x^*[n] = x[n] \).
  3. Evaluate \( X[N-k] = \sum_{n=0}^{N-1} x[n] e^{-j \frac{2\pi}{N} (N-k)n} \)
  4. Simplify exponent: \( e^{-j 2\pi n} e^{j \frac{2\pi}{N} kn} = 1 \cdot e^{j \frac{2\pi}{N} kn} \), proving \( X[N-k] = X^*[k] \).
Parseval's Relation \[ \sum_{n=0}^{N-1} |x[n]|^2 = \frac{1}{N} \sum_{k=0}^{N-1} |X[k]|^2 \] Relates energy in time to energy in frequency.
  1. Start with energy \( E = \sum_{n=0}^{N-1} x[n] x^*[n] \)
  2. Substitute IDFT for \( x[n] \): \( E = \sum_{n=0}^{N-1} \left( \frac{1}{N} \sum_{k=0}^{N-1} X[k] W_N^{-kn} \right) x^*[n] \)
  3. Interchange sums: \( E = \frac{1}{N} \sum_{k=0}^{N-1} X[k] \left( \sum_{n=0}^{N-1} x^*[n] W_N^{-kn} \right) \)
  4. The inner sum is \( X^*[k] \), leaving \( E = \frac{1}{N} \sum_{k=0}^{N-1} X[k] X^*[k] = \frac{1}{N} \sum_{k=0}^{N-1} |X[k]|^2 \).

Core Theory: Cooley-Tukey FFT Algorithm
The Fast Fourier Transform (FFT) reduces the computational complexity of the Discrete Fourier Transform (DFT) from O(N²) to O(N log₂ N). It achieves this by using a divide-and-conquer strategy, recursively breaking down an N-point sequence into smaller sequences.
Decimation in Time (DIT) Decomposition \[X[k] = G[k] + W_N^k H[k]\] By splitting the sequence into even and odd indices, the N-point DFT is expressed as the sum of two N/2-point DFTs (G[k] for even, H[k] for odd). This is the fundamental equation of the Radix-2 DIT FFT.
Twiddle Factor Reduction Proof \[W_N^{2mk} = W_{N/2}^{mk}\] This reduction is possible because squaring the twiddle factor halves its resolution: \((e^{-j 2\pi/N})^2 = e^{-j 4\pi/N} = e^{-j 2\pi/(N/2)}\). This proves that the even and odd sub-sequences form valid N/2-point DFTs.
The Butterfly Operation \[A' = A + W_N^k B\] \[B' = A - W_N^k B\] By exploiting the symmetry property \(W_N^{k+N/2} = -W_N^k\), we can compute two outputs simultaneously. We calculate \(W_N^k B\) once, add it to \(A\) for the top branch, and subtract it for the bottom branch.
Complexity Derivation \[T(N) = 2T(N/2) + \frac{N}{2} \implies T(N) = \frac{N}{2}\log_2 N\]
  1. An N-point DFT requires two N/2-point DFTs: \(2 \times T(N/2)\).
  2. It also requires one multiplication for each of the \(N/2\) butterflies per stage.
  3. Solving the recurrence relation over \(\log_2 N\) stages proves the \(O(N \log N)\) complexity.

Checkpoint 1: Why does a Direct DFT require \(N^2\) complex multiplications, while the FFT reduces this count?
A Direct DFT calculates \(N\) separate frequency bins. Each bin \(X[k]\) is a summation of \(N\) terms, where each term requires a complex multiplication of the form \(x[n] \cdot W_N^{kn}\). Multiplying \(N\) multiplications per bin across all \(N\) bins yields exactly \(N \times N = N^2\) complex multiplications.

The FFT reduces this count by exploiting properties of the twiddle factors (periodicity and symmetry). Rather than calculating each bin independently, the FFT divides the signal into smaller blocks and reuses sub-calculations, breaking the quadratic scaling.
Checkpoint 2: A DSP processor must run in real-time. What is the maximum signal block size \(N\) we can process with direct DFT if our hardware supports up to 1,000,000 operations per second and the sample rate is 1 kHz?
At a sample rate of 1 kHz, we process 1,000 samples per second. 1. For block size \(N\), the direct DFT takes \(N^2\) operations. 2. In one second, we process \(1000 / N\) blocks. 3. The total operations per second is: \[\text{Ops/sec} = \frac{1000}{N} \times N^2 = 1000 N\] 4. Setting this equal to the hardware limit: \[1000 N \le 1,000,000 \implies N \le 1000\] *Note*: With the FFT, the total operations per second is: \[\text{Ops/sec} = \frac{1000}{N} \times \left(\frac{N}{2} \log_2 N\right) = 500 \log_2 N\] For \(N = 1024\), this is only \(500 \times 10 = 5000\) operations per second, representing a tiny fraction (0.5%) of our hardware capability! This reveals why the FFT is essential for processing large blocks.

Core Theory: Radix-2 Decimation-in-Time (DIT) FFT
The Cooley-Tukey Radix-2 Decimation-in-Time (DIT) algorithm reduces the \(O(N^2)\) computational burden of direct DFT computation to \(O(N \log_2 N)\) by recursively partitioning an \(N\)-point sequence into two \(N/2\)-point sequences composed of even-indexed and odd-indexed samples.
DIT Mathematical Decomposition \[ X[k] = \sum_{n=0}^{N-1} x[n] W_N^{nk} = \sum_{r=0}^{N/2-1} x[2r] W_N^{2rk} + \sum_{r=0}^{N/2-1} x[2r+1] W_N^{(2r+1)k} \] \[ X[k] = \sum_{r=0}^{N/2-1} x[2r] W_{N/2}^{rk} + W_N^k \sum_{r=0}^{N/2-1} x[2r+1] W_{N/2}^{rk} = X_e[k] + W_N^k X_o[k] \] Using the twiddle factor periodicity and symmetry properties (\(W_{N/2}^{r(k+N/2)} = W_{N/2}^{rk}\) and \(W_N^{k+N/2} = -W_N^k\)), the top and bottom halves of the spectrum are computed simultaneously: \[ X[k] = X_e[k] + W_N^k X_o[k] \] \[ X[k + N/2] = X_e[k] - W_N^k X_o[k], \quad 0 \le k < N/2 \]
The Butterfly Unit & In-Place Computation \[ A_{out} = A_{in} + W_N^r B_{in}, \qquad B_{out} = A_{in} - W_N^r B_{in} \] Each basic 2-point butterfly takes two inputs \((A, B)\), multiplies the lower branch by twiddle factor \(W_N^r\), and performs an addition and subtraction. Because the outputs can overwrite the inputs in memory, memory storage is exactly \(N\) complex registers (in-place computation).
Bit-Reversal Index Ordering For Radix-2 DIT-FFT, the inputs must be rearranged into bit-reversed order before stage 1, while the outputs emerge in natural frequency order: \[ n = (b_2 b_1 b_0)_2 \implies \text{Bit-Reversed } n_{rev} = (b_0 b_1 b_2)_2 \] For \(N=8\): \(x[0]\to x[0], x[1]\to x[4], x[2]\to x[2], x[3]\to x[6], x[4]\to x[1], x[5]\to x[5], x[6]\to x[3], x[7]\to x[7]\).

Checkpoint 1: Why must the inputs to a decimation-in-time (DIT) FFT be arranged in bit-reversed order?
In DIT-FFT, we repeatedly split the signal into even and odd indices. 1. The first division splits \(x[n]\) into even-indexed samples \(x[2r]\) and odd-indexed samples \(x[2r+1]\). Checkpoint 2: Show that the twiddle factor exponent \(W_8^5 = -W_8^1\). Explain how this reduces multiplications.

Core Theory: Linear Filtering via FFT — Overlap-Add (OLA) Method
In practical DSP, streaming signals \(x[n]\) are continuous and infinitely long, while FIR filter impulse responses \(h[n]\) have finite length \(M\). The Overlap-Add (OLA) method performs fast linear convolution by block-processing \(x[n]\) via FFTs.
OLA Block Partitioning & Zero Padding \[ x[n] = \sum_{m=0}^\infty x_m[n - mL], \qquad x_m[n] = \begin{cases} x[n + mL], & 0 \le n \le L-1 \\ 0, & \text{otherwise} \end{cases} \] Each input block of length \(L\) is zero-padded to length \(N \ge L + M - 1\). The FIR impulse response \(h[n]\) (length \(M\)) is also zero-padded to length \(N\).
Fast Frequency-Domain Convolution \[ Y_m[k] = X_m[k] \cdot H[k] = \text{DFT}_N\{x_m[n]\} \cdot \text{DFT}_N\{h[n]\} \] \[ y_m[n] = \text{IDFT}_N\{Y_m[k]\} \qquad (\text{Length } N = L + M - 1) \] Because \(N \ge L + M - 1\), the circular convolution exactly equals the linear convolution \(y_m[n] = x_m[n] * h[n]\) with no time-domain aliasing.
Reconstruction via Overlap-Addition The overall linear convolution output is synthesized by summing shifted output blocks, overlapping by \(M-1\) samples between consecutive blocks: \[ y[n] = y_0[n] + y_1[n - L] + y_2[n - 2L] + \dots \] The last \(M-1\) samples of block \(m\) are directly added to the first \(M-1\) samples of block \(m+1\).

Checkpoint 2: Why do adjacent blocks overlap in time, and why do we add their values rather than just concatenating them?
When a block of length \(L\) is convolved with a filter of length \(M\), the system's energy decay (the impulse response) extends the convolved output block by \(M - 1\) samples. This means the output block has length \(L + M - 1\).

Since the next input block starts exactly \(L\) samples later, its output will overlap with the previous block's decay tail for \(M - 1\) samples. Because convolution is a linear system, these overlapping outputs must be **added** together to compute the complete linear filtering response. Concatenating them without addition would discard the filter's decay tails, causing severe distortion at the block boundaries.

Core Theory: Linear Filtering via FFT — Overlap-Save (OLS) Method
The Overlap-Save (OLS) (or Overlap-Discard) method computes linear convolution by deliberately overlapping input blocks by \(M-1\) samples, performing circular convolution via FFT/IFFT, and discarding the aliased samples.
OLS Input Block Formulation Each input block \(x_m[n]\) has length \(N = L + M - 1\) and contains the last \(M-1\) points from the previous block as a prefix: \[ x_m[n] = x[mL + n - (M-1)], \quad 0 \le n \le N-1 \] The filter \(h[n]\) is zero-padded to length \(N\).
Circular Convolution & Discard Mechanism \[ \tilde{y}_m[n] = \text{IDFT}_N\{\text{DFT}_N\{x_m[n]\} \cdot \text{DFT}_N\{h[n]\}\} \] Due to circular wrap-around, the first \(M-1\) output points represent cyclic aliasing. The remaining \(L\) points exactly equal the linear convolution: \[ y_m[n] = \begin{cases} \text{DISCARD (Aliased)}, & 0 \le n < M-1 \\ y[mL + n - (M-1)] \; (\text{Valid Linear Conv}), & M-1 \le n < N \end{cases} \]

Output Synthesis Add overlapping tails of length \(M-1\) Discard first \(M-1\) aliased points; abut valid parts
Arithmetic Overhead Requires additions during assembly Zero additions during assembly (pure indexing)

Core Theory: FIR Filter Realization — Direct & Cascade Forms
A discrete-time FIR filter has a finite-duration impulse response and is inherently stable. The realization structure determines memory delay elements, multiplier hardware count, and resilience to coefficient quantization.
Direct Form (Transversal Filter) \[ y[n] = \sum_{k=0}^{M-1} b_k x[n-k] = b_0 x[n] + b_1 x[n-1] + \dots + b_{M-1} x[n-M+1] \] \[ H(z) = \sum_{k=0}^{M-1} b_k z^{-k} \] Direct Form uses a tapped delay line of \(M-1\) unit delays \(z^{-1}\), \(M\) multipliers, and \(M-1\) adders.
Transposed Direct Form Derived by applying Tellegen's Theorem / Flow Graph Reversal: 1. Reverse direction of all signal branches, 2. Swap input and output nodes, 3. Branching nodes become summing nodes. \[ y[n] = b_0 x[n] + v_1[n-1], \quad v_1[n] = b_1 x[n] + v_2[n-1], \quad \dots \] The transposed form eliminates the long adder chain tree, reducing accumulator propagation delay for high-speed VLSI.
Cascade Form Realization Factoring \(H(z)\) into a cascade of second-order real polynomial sections (biquads): \[ H(z) = b_0 \prod_{k=1}^{\lfloor M/2 floor} (1 + eta_{1k} z^{-1} + eta_{2k} z^{-2}) \] Grouping complex conjugate zero pairs \((z_k, z_k^*)\) into second-order stages isolates roots and prevents zero migration under coefficient quantization.

Checkpoint 1: Why does a Direct-Form realization of an \(M\)-tap FIR filter require \(M-1\) delay elements?
An \(M\)-tap FIR filter computes output based on the current sample and \(M-1\) past samples: \[y[n] = h[0]x[n] + h[1]x[n-1] + \dots + h[M-1]x[n-M+1]\] To store these \(M-1\) past samples in memory, we need a shift-register buffer of length \(M-1\). Checkpoint 2: Why are cascade realizations preferred over direct-form realizations in low-cost, fixed-point DSP microcontrollers?

In cascade-form, the filter is factored into second-order sections. Core Theory: Linear-Phase FIR & Frequency-Sampling Realizations
Linear-phase FIR filters possess coefficient symmetry that allows hardware multipliers to be cut in half. Alternatively, frequency-sampling structures realize FIR filters using recursive resonator banks.
Linear-Phase Multiplier Reduction For a symmetric impulse response \(h[n] = h[M-1-n]\), inputs with equal coefficients can be pre-added before multiplication: \[ \text{Even } M: \quad y[n] = \sum_{k=0}^{M/2-1} h[k] (x[n-k] + x[n-M+1+k]) \] \[ \text{Odd } M: \quad y[n] = \sum_{k=0}^{(M-3)/2} h[k] (x[n-k] + x[n-M+1+k]) + h\left[ rac{M-1}{2} ight] x\left[n - rac{M-1}{2} ight] \] This reduces the multiplier requirement from \(M\) to \(\lfloor M/2 floor + 1\) (a 50% savings in DSP MAC hardware).
Frequency-Sampling Structure \[ H(z) = rac{1 - z^{-M}}{M} \sum_{k=0}^{M-1} rac{H[k]}{1 - W_M^{-k} z^{-1}} \] This structure consists of an all-zero FIR comb filter \((1 - z^{-M})\) cascaded with a parallel bank of all-pole discrete resonators with poles placed exactly on the unit circle at \(z = e^{j 2\pi k / M}\). For narrowband filters where many DFT coefficients \(H[k] = 0\), the unneeded resonator branches are eliminated, yielding high computational efficiency.

Core Theory: IIR Realization — Direct Forms I, II & Transposed Forms
Infinite Impulse Response (IIR) filters are recursive systems governed by Linear Constant-Coefficient Difference Equations (LCCDE). Because feedback loops are present, the layout of delay registers directly determines memory footprint and noise properties.
Transfer Function & Direct Form I \[ H(z) = rac{\sum_{k=0}^M b_k z^{-k}}{1 + \sum_{k=1}^N a_k z^{-k}} \implies y[n] = \sum_{k=0}^M b_k x[n-k] - \sum_{k=1}^N a_k y[n-k] \] Direct Form I implements the feedforward zeros and feedback poles as separate delay lines, requiring \(M + N\) delay registers.
Direct Form II (Canonical Realization) By cascading the all-pole subsystem before the all-zero subsystem, the intermediate state variable \(w[n]\) shares a single delay line: \[ w[n] = x[n] - \sum_{k=1}^N a_k w[n-k], \qquad y[n] = \sum_{k=0}^M b_k w[n-k] \] Requires only \(\max(M, N)\) delay elements (canonical memory requirement).
Transposed Direct Form II Flow graph transposition yields state equations where delays follow multipliers: \[ y[n] = b_0 x[n] + v_1[n-1], \quad v_k[n] = b_k x[n] - a_k y[n] + v_{k+1}[n-1] \] Advantages: Multipliers share the same input node \(x[n]\) and \(y[n]\), reducing register pressure and eliminating multi-input adder critical path bottlenecks.

Core Theory: IIR Cascade Realization & Biquad SOS Pairing
High-order direct form IIR filters suffer from severe coefficient quantization sensitivity: small changes in polynomial coefficients cause large shifts in pole positions, risking instability. Cascade realization breaks the system into second-order sections (biquads).
Second-Order Section (Biquad) Formulation \[ H(z) = g \prod_{k=1}^K H_k(z) = g \prod_{k=1}^K rac{b_{k0} + b_{k1} z^{-1} + b_{k2} z^{-2}}{1 + a_{k1} z^{-1} + a_{k2} z^{-2}} \] Each 2nd-order section contains a complex-conjugate pole pair \(p_k, p_k^*\) and zero pair \(z_k, z_k^*\).
Optimal Pole-Zero Pairing & Section Ordering Rules

1. Pairing: Pair complex conjugate poles \(p_k\) with the closest transmission zeros \(z_k\) in the \(z\)-plane to keep the section frequency response \(|H_k(e^{j\omega})|\) as flat as possible, minimizing peak-to-average gain.

2. Ordering: Order the sections in sequence of increasing \(Q\)-factor (increasing pole radius \(r_k o 1\)) to maximize signal dynamic range and avoid internal register overflow.

3. Scaling: Introduce section gain scaling factors \(s_k\) between stages to maintain optimal signal-to-noise ratio (SNR) under \(L_2\) or \(L_\infty\) norm constraints.

Core Theory: IIR Parallel Realization
The Parallel Realization of an IIR filter is obtained via Partial Fraction Expansion (PFE) of the transfer function \(H(z)\). All sections operate concurrently on the input signal, and their outputs are summed.
Partial Fraction Expansion Structure \[ H(z) = C + \sum_{k=1}^{K_1} rac{A_k}{1 - p_k z^{-1}} + \sum_{k=1}^{K_2} rac{\gamma_{k0} + \gamma_{k1} z^{-1}}{1 + a_{k1} z^{-1} + a_{k2} z^{-2}} \] Where \(C = b_M / a_N\) when \(M = N\). Real poles form 1st-order parallel branches; complex-conjugate pole pairs are combined into 2nd-order real branches.
Engineering Advantages of Parallel Realization

1. Independent Noise Sources: Roundoff noise generated in one section is directly output to the summer without passing through the poles of downstream sections.

2. Pipelining & Concurrency: Parallel sections can execute simultaneously on multicore DSPs or parallel FPGA hardware blocks, minimizing latency.

3. Low Sensitivity: Pole locations are determined solely by the denominator coefficients of their respective individual branch.

Core Theory: Lattice & Lattice-Ladder Structures & Finite Word-Length Effects
Lattice structures use reflection coefficients (PARCOR coefficients \(k_m\)) to realize FIR and IIR filters with exceptional stability and low sensitivity to coefficient quantization.
FIR Lattice Equations \[ f_m[n] = f_{m-1}[n] + k_m g_{m-1}[n-1] \] \[ g_m[n] = k_m f_{m-1}[n] + g_{m-1}[n-1] \] Where \(f_m[n]\) is the forward prediction error and \(g_m[n]\) is the backward prediction error.
IIR Lattice-Ladder & Stability Condition For an all-pole IIR lattice or general pole-zero lattice-ladder, stability is guaranteed if and only if every reflection coefficient satisfies: \[ |k_m| < 1 \quad \forall m = 1, 2, \dots, N \qquad (\text{Schur-Cohn Stability Criterion}) \]
Finite Word-Length Effects (FWE)

1. Coefficient Quantization: Shifts pole/zero positions in the \(z\)-plane; mitigated by cascade/lattice forms.

2. Round-off Noise: Fixed-point multiplication truncates \(2B\)-bit products to \(B\) bits, modeled as additive white noise of variance \(\sigma_e^2 = rac{2^{-2B}}{12}\).

3. Limit Cycle Oscillations: Zero-input limit cycles caused by truncation quantization, and overflow oscillations caused by two's complement wrap-around (prevented using saturation arithmetic).

Checkpoint 1: Why can we not design a Highpass filter using a Type II (Symmetric, Even length) FIR structure?
For a Type II FIR filter, the impulse response is symmetric: \(h[n] = h[M-1-n]\), and the filter length \(M\) is even.

Let's evaluate the frequency response at Nyquist frequency (\(\omega = \pi\)): \[H(e^{j\pi}) = \sum_{n=0}^{M-1} h[n] e^{-jn\pi} = \sum_{n=0}^{M-1} h[n] (-1)^n\]
Since \(M\) is even, the indices are paired: \(n=0\) is paired with \(M-1\) (which is odd). Thus, \(h[0](-1)^0 = h[0]\) and \(h[M-1](-1)^{M-1} = -h[M-1]\). Since \(h[0] = h[M-1]\), these terms sum to zero: \(h[0] - h[M-1] = 0\). This perfect cancellation occurs for all pairs across the impulse response, forcing: \[H(e^{j\pi}) = 0\]
Because the Nyquist frequency (\(\omega = \pi\)) is forced to be a zero, the filter cannot pass high frequencies. Therefore, Type II structures cannot be used to realize Highpass or Bandstop filters.
Checkpoint 2: If a linear-phase FIR filter has a complex zero at \(z = 0.5e^{j\pi/3}\), list the locations of the other zeros that must exist due to symmetry.

Moving average (MA) filters are the most common simple FIR smoothing filters. Understanding the structural trade-offs between FIR and IIR architectures is central to system-level DSP design.
Moving-Average Filter Theory \[ y[n] = rac{1}{M} \sum_{k=0}^{M-1} x[n-k] \implies H(z) = rac{1 - z^{-M}}{M(1 - z^{-1})} \] \[ H(e^{j\omega}) = rac{1}{M} rac{\sin(\omega M / 2)}{\sin(\omega / 2)} e^{-j\omega(M-1)/2} \] The zeros are located on the unit circle at \(z_k = e^{j 2\pi k / M}\) for \(k = 1, 2, \dots, M-1\). The pole at \(z=1\) cancels the zero at \(z=1\).

Checkpoint 1: Explain how an IIR filter can meet the same magnitude specifications as an FIR filter but with a much lower filter order.
* **FIR Zeros**: An FIR filter only has zeros (poles are fixed at the origin \(z=0\)). To create a sharp transition roll-off, it must use many zeros to shape the frequency response, requiring a high filter order. * **IIR Poles**: An IIR filter contains both poles and zeros. Placing poles close to the unit circle (inside \(|z|=1\)) creates sharp resonances (peaks) that can drop off very rapidly to zero. This active pole-shaping allows the filter to achieve extremely sharp transitions with very few coefficients, resulting in a much lower order.
Checkpoint 2: Prove that the pole at \(z=1\) in an \(N\)-point Moving Average filter does not cause instability.
The system function of the moving average filter is: \[H(z) = \frac{1}{N} \left( \frac{1 - z^{-N}}{1 - z^{-1}} \right)\] Evaluating the numerator at \(z=1\) yields \(1 - 1^{-N} = 0\). Since both numerator and denominator vanish at \(z=1\), we apply L'Hôpital's rule: \[\lim_{z \to 1} H(z) = \lim_{z \to 1} \frac{\frac{d}{dz}(1 - z^{-N})}{\frac{d}{dz}(N - N z^{-1})} = \lim_{z \to 1} \frac{N z^{-N-1}}{N z^{-2}} = 1\] Thus, the pole at \(z=1\) is mathematically canceled by the zero at \(z=1\), leaving only \(N-1\) poles at the origin \(z=0\). Since all active poles are at \(z=0\) (which is inside the unit circle), the system is stable.

Core Theory: Analog Filter Prototypes (Butterworth & Chebyshev)
IIR digital filter design typically transforms well-established continuous-time analog filter prototypes (Butterworth, Chebyshev) into discrete transfer functions.
Butterworth Approximation (Maximally Flat) \[ |H_a(j\Omega)|^2 = rac{1}{1 + (\Omega / \Omega_c)^{2N}} \] All \(2N-1\) derivatives of \(|H_a(j\Omega)|^2\) are zero at \(\Omega=0\). The poles lie on an ellipse in the left-half \(s\)-plane, achieving a much steeper transition roll-off than Butterworth for the same order \(N\).

Checkpoint 1: For a given set of filter specifications (\(\Omega_p, \Omega_s, \alpha_p, \alpha_s\)), which filter approximation will yield a lower filter order: Butterworth or Chebyshev?
The **Chebyshev** approximation will always yield a lower filter order than the Butterworth approximation.

Butterworth has a maximally flat passband and decays monotonically. To achieve a sharp roll-off, it requires a high order. Chebyshev allows ripples in the passband (Type I) or stopband (Type II) to distribute the approximation error uniformly. This trade-off allows Chebyshev filters to achieve a much steeper roll-off near the band edge, meeting the same stopband specifications with a significantly lower order.
Checkpoint 2: Why do the poles of a Butterworth filter lie on a circle, while the poles of a Chebyshev Type I filter lie on an ellipse?
* **Butterworth Poles**: For a Butterworth filter, the poles are the LHP roots of \(s^{2N} + (-1)^N \Omega_c^{2N} = 0\). Solving this equation yields poles with a constant magnitude \(|s_k| = \Omega_c\). Since the magnitude is constant, all poles must lie on a circle of radius \(\Omega_c\). * **Chebyshev Poles**: For a Chebyshev Type I filter, the passband ripple alters the pole equations. The poles are compressed along the real axis by the factor \(\sinh(\phi)\) and stretched along the imaginary axis by the factor \(\cosh(\phi)\), where \(\phi\) depends on the ripple parameter \(\epsilon\). Since these horizontal and vertical scaling factors are different, the pole positions form an ellipse.

Core Theory: Impulse Invariance Method for IIR Filter Design
The Impulse Invariance Method samples the impulse response of an analog filter to create a digital filter: \(h[n] = T_d h_a(n T_d)\).
Pole Mapping & Partial Fraction Transformation \[ H_a(s) = \sum_{k=1}^N rac{A_k}{s - p_k} \implies H(z) = \sum_{k=1}^N rac{A_k}{1 - e^{p_k T_d} z^{-1}} \] Each \(s\)-plane pole \(p_k = \sigma_k + j\Omega_k\) maps directly to a \(z\)-plane pole \(z_k = e^{p_k T_d} = e^{\sigma_k T_d} e^{j\Omega_k T_d}\). Left-half \(s\)-plane poles (\(\sigma_k < 0\)) map strictly inside the unit circle (\(|z_k| < 1\)), guaranteeing stability.
Aliasing Limitation The discrete frequency response is an infinite periodic sum of shifted analog frequency responses: \[ H(e^{j\omega}) = \sum_{k=-\infty}^\infty H_a\left(j rac{\omega + 2\pi k}{T_d} ight) \] Because analog filters are not strictly bandlimited, spectral aliasing always occurs. Consequently, Impulse Invariance is suitable only for lowpass and bandpass filters with high stopband attenuation; it cannot be used for highpass or bandstop filters.

Core Theory: Bilinear Transformation (BLT) Method
The Bilinear Transformation uses trapezoidal numerical integration to map the continuous \(s\)-domain to the discrete \(z\)-domain without any spectral aliasing.
Conformal Mapping & Frequency Warping \[ s = rac{2}{T_d} rac{1 - z^{-1}}{1 + z^{-1}} \implies z = rac{1 + s T_d / 2}{1 - s T_d / 2} \] Substituting \(s = j\Omega\) maps the entire infinite analog frequency axis \(-\infty < \Omega < \infty\) into the unit circle \(z = e^{j\omega}\) over \(-\pi < \omega \le \pi\): \[ \Omega = \frac{2}{T_d} \tan\left(\frac{\omega}{2}\right) \iff \omega = 2 \arctan\left(\frac{\Omega T_d}{2}\right) \]

Prewarp digital frequencies \(\omega_p, \omega_s o \Omega_p, \Omega_s\);
2. Design continuous-time analog prototype \(H_a(s)\);
3. Substitute \(s = rac{2}{T_d} rac{1-z^{-1}}{1+z^{-1}}\) to yield the final discrete transfer function \(H(z)\).

Core Theory: Matched Z-Transform & Spectral Transformations
The Matched Z-Transform (MZT) directly maps analog poles and zeros into the \(z\)-plane. Digital-to-digital spectral transformations allow designing Highpass, Bandpass, and Bandstop filters directly from a discrete Lowpass prototype.
Matched Z-Transform (MZT) \[ H_a(s) = K rac{\prod_{i=1}^M (s - z_i)}{\prod_{k=1}^N (s - p_k)} \implies H(z) = K_d \frac{\prod_{i=1}^M (1 - e^{z_i T_d} z^{-1})}{\prod_{k=1}^N (1 - e^{p_k T_d} z^{-1})} (1 + z^{-1})^{N-M} \] Factors of \((1 + z^{-1})\) (zeros at \(z = -1\), \(\omega = \pi\)) are added to match zero gain at half the sampling frequency.
Digital Spectral Transformations (Constantinides) Substituting \(z^{-1} o g(z^{-1})\) converts a Lowpass filter with cutoff \( heta_p\) into other filter types with cutoff \(\omega_p\): \[ \text{Lowpass to Highpass: } z^{-1} \to -\frac{z^{-1} + \alpha}{1 + \alpha z^{-1}}, \qquad \alpha = -\frac{\cos[(\theta_p + \omega_p)/2]}{\cos[(\theta_p - \omega_p)/2]} \] \[ \text{Lowpass to Bandpass: } z^{-1} \to -\frac{z^{-2} - \frac{2\alpha k}{k+1} z^{-1} + \frac{k-1}{k+1}}{\frac{k-1}{k+1} z^{-2} - \frac{2\alpha k}{k+1} z^{-1} + 1} \]

Checkpoint 1: What is the main danger of using a zero-forcing equalizer (\(E(z) = 1/C(z)\)) in a channel that has a deep spectral null (very low gain at a specific frequency)?
* **Notch Amplification**: If the channel has a deep spectral null, \(C(e^{j\omega}) \approx 0\) at that frequency. This phenomenon is known as **noise enhancement**.
Checkpoint 2: In the LMS update equation, what happens if the step-size parameter \(\mu\) is chosen too large or too small?
* **Too Large**: If \(\mu\) is too large, the algorithm converges quickly but may overshoot the optimal coefficients, leading to stability issues or failure to converge (divergence/oscillation). * **Too Small**: If \(\mu\) is too small, the filter weights adjust very slowly, requiring a long convergence time. The filter may fail to track rapid changes in non-stationary environments.
