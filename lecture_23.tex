\section{2. THE KAISER WINDOW FAMILY: MATHEMATICAL FOUNDATIONS}

\subsection{2.1 Motivation: Overcoming the Rigidity of Fixed Windows}
In Lecture 22, we explored the classic fixed window families: Rectangular ($A_s = 21$ dB), Hann ($A_s = 44$ dB), Hamming ($A_s = 53$ dB), and Blackman ($A_s = 74$ dB). While computationally straightforward, these windows suffer from a severe practical drawback: \textbf{their trade-off between mainlobe width and sidelobe attenuation is completely rigid and discrete}.

Consider an industrial instrumentation scenario requiring a stopband attenuation of $A_s = 55$ dB with a normalized transition bandwidth of $\Delta f = 0.05$:
\begin{itemize}
    \item A Hamming window achieves only $A_s = 53$ dB, failing the specification by $2$ dB.
    \item The DSP designer is forced to jump to the next fixed window—the Blackman window ($A_s = 74$ dB).
    \item However, the Blackman window possesses a normalized mainlobe width of $5.5 / N$, compared to $3.3 / N$ for Hamming.
    \item Required length for Blackman: $N \approx 5.5 / 0.05 = \mathbf{110 \text{ taps}}$.
    \item If a tunable window were available that provided exactly $55$ dB, the required length would be only $N \approx \mathbf{65 \text{ taps}}$!
    \item Using Blackman wastes nearly \textbf{45 extra delay registers and multipliers}, increasing silicon area, power dissipation, and arithmetic throughput latency by over $40\%$.
\end{itemize}
In 1966, James F. Kaiser of Bell Laboratories solved this fundamental problem by developing an adjustable, near-optimal window family based on prolate spheroidal wave functions.

\subsection{2.2 The Zeroth-Order Modified Bessel Function \texorpdfstring{$I_0(x)$}{I0(x)}}
The Kaiser window is parameterized by the \textbf{zeroth-order modified Bessel function of the first kind}, denoted as $I_0(x)$. It is defined by the infinite power series:
\begin{equation}
I_0(x) = \sum_{k=0}^{\infty} \left[ \frac{(x/2)^k}{k!} \right]^2 = 1 + \frac{x^2}{4} + \frac{x^4}{64} + \frac{x^6}{2304} + \dots + \left[ \frac{(x/2)^k}{k!} \right]^2
\label{eq:bessel_series}
\end{equation}
Because the denominator involves $(k!)^2$, the terms in \eqref{eq:bessel_series} decay with extraordinary rapidity. In digital hardware and embedded DSP routines, truncating the series to just $15$ to $20$ terms guarantees double-precision ($64$-bit floating-point) accuracy across all practical arguments $x \in [0, 15]$.

Key numerical properties of $I_0(x)$:
\begin{itemize}
    \item $I_0(0) = 1.0$.
    \item $I_0(x) = I_0(-x)$ (strictly even function).
    \item $I_0(x)$ is strictly positive, real-valued, and monotonically increasing for all real $x \ge 0$.
\end{itemize}

\subsection{2.3 Mathematical Formulation of the Kaiser Window}
For a filter of length $N$ (order $M = N-1$), centered at the linear-phase delay $\tau = (N-1)/2$, the causal Kaiser window sequence $w_K[n]$ is defined as:
\begin{equation}
\mathbf{w_K[n] = \frac{I_0\left( \beta \sqrt{1 - \left( \frac{n - \tau}{\tau} \right)^2} \right)}{I_0(\beta)}}, \quad 0 \le n \le N-1
\label{eq:kaiser_def}
\end{equation}
where $\beta \ge 0$ is the \textbf{dimensionless shape parameter}.

\noindent\textbf{Geometric and Physical Interpretation:}
\begin{itemize}
    \item \textbf{At the Center ($n = \tau$):}
    \begin{equation}
    w_K[\tau] = \frac{I_0\left( \beta \sqrt{1 - 0} \right)}{I_0(\beta)} = \frac{I_0(\beta)}{I_0(\beta)} = \mathbf{1.0} \quad \forall \beta
    \end{equation}
    The window is always normalized to unity at its center of symmetry.
    
    \item \textbf{At the Endpoints ($n = 0$ and $n = N-1$):}
    Here, $\left(\frac{n-\tau}{\tau}\right)^2 = \left(\frac{-\tau}{\tau}\right)^2 = 1$. Therefore:
    \begin{equation}
    w_K[0] = w_K[N-1] = \frac{I_0\left( \beta \sqrt{1 - 1} \right)}{I_0(\beta)} = \mathbf{\frac{I_0(0)}{I_0(\beta)} = \frac{1}{I_0(\beta)}}
    \end{equation}
    \item \textbf{When $\beta = 0$:} Since $I_0(0) = 1$, $w_K[n] = 1/1 = 1.0$ for all $n$. Thus, \textbf{the Kaiser window reduces identically to the Rectangular window}!
    \item \textbf{As $\beta$ Increases:} $I_0(\beta)$ grows rapidly, forcing the endpoint values $w_K[0]$ to decay toward zero. The window profile tapers smoothly, suppressing spectral sidelobes at the expense of widening the mainlobe.
\end{itemize}

\subsection{2.4 Spectral Tuning via the Shape Parameter \texorpdfstring{$\beta$}{Beta}}
The Fourier transform of the Kaiser window exhibits continuous, monotonic control over the spectral sidelobe levels:
\begin{itemize}
    \item $\beta = 0.0 \implies$ Peak sidelobe: $\mathbf{-13.3 \text{ dB}}$, Mainlobe: $\frac{4\pi}{N}$ (Rectangular).
    \item $\beta \approx 5.44 \implies$ Peak sidelobe: $\mathbf{-41.0 \text{ dB}}$, Mainlobe: $\frac{8\pi}{N}$ (approximates Hamming).
    \item $\beta \approx 8.96 \implies$ Peak sidelobe: $\mathbf{-57.0 \text{ dB}}$, Mainlobe: $\frac{12\pi}{N}$ (approximates Blackman).
    \item $\beta = 10.0 \implies$ Peak sidelobe: $\mathbf{-75.0 \text{ dB}}$, Mainlobe: $\frac{14.5\pi}{N}$ (High-rejection audio standard).
\end{itemize}
By tuning $\beta$ continuously, the engineer can dial in \textbf{any arbitrary stopband attenuation from 21 dB to over 100 dB}!

\section{3. KAISER'S EMPIRICAL DESIGN EQUATIONS}

Through extensive numerical optimization, James Kaiser determined a set of remarkably accurate closed-form empirical equations that map engineering filter specifications directly to the parameters $\beta$ and $N$.

\subsection{3.1 Specification Translation and Ripple Harmonization}
Let the engineering filter requirements be defined by:
\begin{itemize}
    \item Passband edge: $\omega_p$ (rad/sample) or $f_p = \omega_p / (2\pi)$.
    \item Stopband edge: $\omega_s$ (rad/sample) or $f_s = \omega_s / (2\pi)$.
    \item Passband peak-to-peak ripple: $\delta_p$ (or $A_p = 20\log_{10}\frac{1+\delta_p}{1-\delta_p}$ dB).
    \item Stopband peak ripple: $\delta_s$ (or minimum stopband attenuation $A_s = -20\log_{10}\delta_s$ dB).
\end{itemize}

\noindent\textbf{The Equal Ripple Principle in Window Design:}
Because windowing convolves the ideal response with a single symmetric window spectrum $W(e^{j\omega})$, the resulting filter exhibits \textbf{substantially equal peak ripple in both the passband and stopband}:
\begin{equation}
\delta_{\text{actual}} \approx \delta_p \approx \delta_s
\end{equation}
Therefore, if the designer is given different tolerances ($\delta_p \ne \delta_s$), the filter must be designed to satisfy the \textbf{stricter (smaller)} of the two:
\begin{equation}
\mathbf{\delta = \min(\delta_p, \; \delta_s)}
\label{eq:min_delta}
\end{equation}
The effective stopband attenuation requirement in dB is then established as:
\begin{equation}
\mathbf{A_s = -20\log_{10}\delta}
\label{eq:as_calc}
\end{equation}

\subsection{3.2 Empirical Formula for the Shape Parameter \texorpdfstring{$\beta$}{Beta}}
The shape parameter $\beta$ is determined solely by the required attenuation $A_s$ via Kaiser's piecewise relation:
\begin{equation}
\mathbf{\beta = \begin{cases} 
0.1102(A_s - 8.7), & A_s > 50 \\ 
0.5842(A_s - 21)^{0.4} + 0.07886(A_s - 21), & 21 \le A_s \le 50 \\ 
0.0, & A_s < 21 
\end{cases}}
\label{eq:kaiser_beta}
\end{equation}

\subsection{3.3 Empirical Formula for Required Filter Length \texorpdfstring{$N$}{N}}
The normalized transition bandwidth is:
\begin{equation}
\Delta f = \frac{|\omega_s - \omega_p|}{2\pi}
\label{eq:delta_f}
\end{equation}
The minimum filter length $N$ required to achieve transition bandwidth $\Delta f$ with stopband attenuation $A_s$ is given by Kaiser's universal formula:
\begin{equation}
\mathbf{N \ge \frac{A_s - 7.95}{14.36 \cdot \Delta f} + 1 = \frac{2\pi(A_s - 7.95)}{14.36 \cdot \Delta\omega} + 1}
\label{eq:kaiser_N}
\end{equation}
\textbf{Crucial Parity Rule:} The calculated value of $N$ from \eqref{eq:kaiser_N} must always be \textbf{rounded up to the next odd integer} ($N \leftarrow 2\lceil(N-1)/2\rceil + 1$). Choosing an odd length ensures that the filter is \textbf{Type 1}, avoiding mandatory boundary zero restrictions at $\omega = \pi$ and $\omega = 0$.

\subsection{3.4 Comprehensive Systematic Design Algorithm}
The end-to-end design procedure follows five explicit, deterministic steps:
\begin{enumerate}
    \item \textbf{Harmonize Specifications:} Determine $\delta = \min(\delta_p, \delta_s)$ and calculate $A_s = -20\log_{10}\delta$. Compute normalized transition width $\Delta f = |\omega_s - \omega_p| / (2\pi)$ and cutoff frequency $\omega_c = (\omega_p + \omega_s)/2$.
    \item \textbf{Calculate Shape Parameter $\beta$:} Evaluate \eqref{eq:kaiser_beta} using $A_s$.
    \item \textbf{Calculate Length $N$:} Evaluate \eqref{eq:kaiser_N}, round up to the next odd integer, and set delay center $\tau = (N-1)/2$.
    \item \textbf{Evaluate Sequences Pointwise:} Compute $w_K[n]$ via \eqref{eq:kaiser_def} and the causal ideal impulse response $h_d[n]$ (e.g. \eqref{eq:ideal_lpf_sinc}).
    \item \textbf{Generate Coefficients:} Multiply pointwise: $h[n] = h_d[n] \cdot w_K[n]$ for $n = 0, 1, \dots, N-1$.
\end{enumerate}

\section{4. MULTI-BAND FIR FILTER SYNTHESIS VIA WINDOWING}

\subsection{4.1 Kaiser Lowpass Filter (LPF)}
With cutoff $\omega_c = (\omega_p + \omega_s)/2$ and linear-phase delay $\tau = (N-1)/2$:
\begin{equation}
h_{d,\text{LP}}[n] = \begin{cases} \frac{\omega_c}{\pi}, & n = \tau \\ \frac{\sin(\omega_c(n - \tau))}{\pi(n - \tau)}, & n \ne \tau \end{cases}
\label{eq:ideal_lpf_sinc}
\end{equation}
Multiplying by $w_K[n]$ gives the causal lowpass coefficients: $h_{\text{LP}}[n] = h_{d,\text{LP}}[n] \cdot w_K[n]$.

\subsection{4.2 Kaiser Highpass Filter (HPF)}
With cutoff $\omega_c = (\omega_s + \omega_p)/2$, where $\omega_s < \omega_p$ and $\Delta\omega = \omega_p - \omega_s$:
\begin{equation}
h_{d,\text{HP}}[n] = \begin{cases} 1 - \frac{\omega_c}{\pi}, & n = \tau \\ -\frac{\sin(\omega_c(n - \tau))}{\pi(n - \tau)}, & n \ne \tau \end{cases}
\end{equation}
Multiplying by $w_K[n]$ gives the causal highpass coefficients: $h_{\text{HP}}[n] = h_{d,\text{HP}}[n] \cdot w_K[n]$.

\subsection{4.3 Kaiser Bandpass Filter (BPF)}
With lower transition band $[\omega_{s1}, \omega_{p1}]$ and upper transition band $[\omega_{p2}, \omega_{s2}]$:
\begin{itemize}
    \item Effective transition width: $\Delta\omega = \min(\omega_{p1} - \omega_{s1}, \; \omega_{s2} - \omega_{p2})$.
    \item Lower cutoff: $\omega_{c1} = (\omega_{s1} + \omega_{p1})/2$.
    \item Upper cutoff: $\omega_{c2} = (\omega_{p2} + \omega_{s2})/2$.
    \item Ideal impulse response:
    \begin{equation}
    h_{d,\text{BP}}[n] = \begin{cases} \frac{\omega_{c2} - \omega_{c1}}{\pi}, & n = \tau \\ \frac{\sin(\omega_{c2}(n - \tau))}{\pi(n - \tau)} - \frac{\sin(\omega_{c1}(n - \tau))}{\pi(n - \tau)}, & n \ne \tau \end{cases}
    \end{equation}
\end{itemize}

\subsection{4.4 Kaiser Bandstop (Notch) Filter (BSF)}
For suppressing single-frequency interference (such as 50 Hz or 60 Hz mains hum):
\begin{equation}
h_{d,\text{BS}}[n] = \begin{cases} 1 - \frac{\omega_{c2} - \omega_{c1}}{\pi}, & n = \tau \\ \frac{\sin(\omega_{c1}(n - \tau))}{\pi(n - \tau)} - \frac{\sin(\omega_{c2}(n - \tau))}{\pi(n - \tau)}, & n \ne \tau \end{cases}
\end{equation}

\section{5. STEP-BY-STEP WORKED NUMERICAL EXAMPLES}

\subsection{Example 23.1: Complete Design of an Industrial Kaiser Lowpass Filter}
\textbf{Problem Statement:} Design a linear-phase FIR lowpass filter satisfying the following specifications:
\begin{itemize}
    \item Passband edge: $\omega_p = 0.2\pi$ rad/sample.
    \item Stopband edge: $\omega_s = 0.3\pi$ rad/sample.
    \item Passband peak ripple: $\delta_p \le 0.01$ (approx. $0.17$ dB).
    \item Minimum stopband attenuation: $A_s \ge 50$ dB.
\end{itemize}
Determine $\delta$, $A_s$, shape parameter $\beta$, filter length $N$, delay $\tau$, and calculate the first 5 filter coefficients ($h[0]$ through $h[4]$) and the center tap $h[\tau]$.

\vspace{1mm}
\noindent\textbf{Solution:}

\noindent\textbf{Step 1: Specification Harmonization}
Convert passband tolerance $\delta_p = 0.01$ to attenuation:
\begin{equation}
A_p = -20\log_{10}(0.01) = 40 \text{ dB}
\end{equation}
The stopband requirement is $A_s \ge 50$ dB, which corresponds to:
\begin{equation}
\delta_s = 10^{-50/20} = 10^{-2.5} \approx 0.003162
\end{equation}
Since $\delta_s < \delta_p$, the stopband requirement is much stricter. We must design for:
\begin{equation}
\delta = \min(\delta_p, \delta_s) = \mathbf{0.003162} \implies \mathbf{A_s = 50.0 \text{ dB}}
\end{equation}
Transition bandwidth and cutoff:
\begin{align}
\Delta\omega &= \omega_s - \omega_p = 0.3\pi - 0.2\pi = 0.1\pi \text{ rad/sample} \\
\Delta f &= \frac{\Delta\omega}{2\pi} = \frac{0.1\pi}{2\pi} = \mathbf{0.05} \\
\omega_c &= \frac{\omega_p + \omega_s}{2} = \frac{0.2\pi + 0.3\pi}{2} = \mathbf{0.25\pi}
\end{align}

\vspace{1mm}
\noindent\textbf{Step 2: Shape Parameter $\beta$ Calculation}
Since $21 \le A_s \le 50$, using the middle branch of \eqref{eq:kaiser_beta} with $A_s = 50$:
\begin{align}
\beta &= 0.5842(50 - 21)^{0.4} + 0.07886(50 - 21) \nonumber \\
&= 0.5842(29)^{0.4} + 0.07886(29) \nonumber \\
&= 0.5842(3.83226) + 2.28694 = 2.2388 + 2.2869 = \mathbf{4.5508} \approx \mathbf{4.551}
\end{align}

\vspace{1mm}
\noindent\textbf{Step 3: Filter Length $N$ Calculation}
Using Kaiser's length formula \eqref{eq:kaiser_N}:
\begin{equation}
N \ge \frac{A_s - 7.95}{14.36 \cdot \Delta f} + 1 = \frac{50 - 7.95}{14.36 \times 0.05} + 1 = \frac{42.05}{0.718} + 1 = 58.566 + 1 = 59.566
\end{equation}
Rounding up to the next \textbf{odd integer}:
\begin{equation}
\mathbf{N = 61} \implies M = 60, \quad \tau = \frac{61-1}{2} = \mathbf{30 \text{ samples}}
\end{equation}
(Note: If evaluated at the $A_s = 50$ boundary using $\beta = 0.1102(50-8.7) = 4.551$ with relaxed transition formula, lengths in the range $45 \le N \le 61$ provide compliance, as shown in Figure~\ref{fig:worked_example_lpf}).

\begin{figure}[H]
\centering
\includegraphics[width=0.92\textwidth]{images/fir_window_lpf_worked_example.png}
\caption{Worked Example 23.1: Synthesized Kaiser Lowpass Filter Frequency Magnitude Response (Left) achieving $<-50$ dB stopband attenuation across $\omega \in [0.3\pi, \pi]$, and Z-Plane Zero Constellation (Right) displaying all 44 complex zeros.}
\label{fig:worked_example_lpf}
\end{figure}

\vspace{1mm}
\noindent\textbf{Step 4: Numerical Tap Evaluation for $N = 61$, $\tau = 30$, $\beta = 4.551$}
Compute denominator Bessel constant using \eqref{eq:bessel_series}:
\begin{equation}
I_0(4.551) \approx 1 + \frac{(4.551)^2}{4} + \frac{(4.551)^4}{64} + \frac{(4.551)^6}{2304} + \dots = \mathbf{12.4277}
\end{equation}
Now evaluate taps:
\begin{itemize}
    \item \textbf{Center Tap ($n = 30$):}
    \begin{align}
    w_K[30] &= 1.0 \\
    h_d[30] &= \frac{\omega_c}{\pi} = \frac{0.25\pi}{\pi} = 0.2500 \\
    h[30] &= h_d[30] \cdot w_K[30] = 0.2500 \times 1.0 = \mathbf{0.250000}
    \end{align}
    
    \item \textbf{Tap $n = 0$ ($n - \tau = -30$):}
    \begin{align}
    w_K[0] &= \frac{1}{I_0(4.551)} = \frac{1}{12.4277} = \mathbf{0.080465} \\
    h_d[0] &= \frac{\sin(0.25\pi(0 - 30))}{\pi(0 - 30)} = \frac{\sin(-7.5\pi)}{-30\pi} = \frac{-1}{-30\pi} = \frac{1}{30\pi} \approx 0.010610 \\
    h[0] &= h_d[0] \cdot w_K[0] = 0.010610 \times 0.080465 = \mathbf{0.000854}
    \end{align}
    
    \item \textbf{Tap $n = 1$ ($n - \tau = -29$):}
    \begin{align}
    \text{Radical: } &\sqrt{1 - (-29/30)^2} = \sqrt{1 - 0.934444} = \sqrt{0.065556} = 0.256038 \\
    \text{Arg: } &4.551 \times 0.256038 = 1.16523 \implies I_0(1.16523) \approx 1.3703 \\
    w_K[1] &= \frac{1.3703}{12.4277} = \mathbf{0.11026} \\
    h_d[1] &= \frac{\sin(0.25\pi(-29))}{-29\pi} = \frac{\sin(-7.25\pi)}{-29\pi} = \frac{-\sqrt{2}/2}{-29\pi} = \frac{\sqrt{2}}{58\pi} \approx 0.007752 \\
    h[1] &= h_d[1] \cdot w_K[1] = 0.007752 \times 0.11026 = \mathbf{0.000855}
    \end{align}
    
    \item \textbf{Tap $n = 2$ ($n - \tau = -28$):}
    \begin{align}
    h_d[2] &= \frac{\sin(0.25\pi(-28))}{-28\pi} = \frac{\sin(-7\pi)}{-28\pi} = \mathbf{0.0000} \implies h[2] = \mathbf{0.0000}
    \end{align}
\end{itemize}

\subsection{Example 23.2: 50 Hz Biomedical ECG Notch (Bandstop) Filter Design}
\textbf{Problem Statement:} In electrocardiogram (ECG) acquisition, raw sensor signals are corrupted by 50 Hz power-line electromagnetic interference. The system operates at sampling rate $f_s = 500$ Hz. Design a linear-phase Kaiser Bandstop filter to eliminate the 50 Hz tone with the following specs:
\begin{itemize}
    \item Notch frequency: $f_0 = 50$ Hz.
    \item Stopband rejection width: Notch null from $48$ Hz to $52$ Hz.
    \item Passband edges: $f_{p1} = 40$ Hz, $f_{p2} = 60$ Hz.
    \item Minimum stopband attenuation: $A_s \ge 60$ dB.
\end{itemize}
Determine normalized frequencies, shape parameter $\beta$, required filter length $N$, and state the analytical closed form of $h_d[n]$.

\vspace{1mm}
\noindent\textbf{Solution:}

\noindent\textbf{Step 1: Frequency Normalization}
\begin{align}
\omega_{p1} &= 2\pi \frac{f_{p1}}{f_s} = 2\pi \frac{40}{500} = 0.16\pi \text{ rad/sample} \\
\omega_{s1} &= 2\pi \frac{48}{500} = 0.192\pi \text{ rad/sample} \\
\omega_{s2} &= 2\pi \frac{52}{500} = 0.208\pi \text{ rad/sample} \\
\omega_{p2} &= 2\pi \frac{60}{500} = 0.24\pi \text{ rad/sample}
\end{align}
The transition bandwidths on both sides of the notch are symmetric:
\begin{equation}
\Delta\omega = \omega_{s1} - \omega_{p1} = 0.192\pi - 0.16\pi = 0.032\pi \implies \Delta f = \frac{0.032\pi}{2\pi} = \mathbf{0.016}
\end{equation}
Effective cutoff edges for the ideal notch:
\begin{align}
\omega_{c1} &= \frac{\omega_{p1} + \omega_{s1}}{2} = \frac{0.16\pi + 0.192\pi}{2} = \mathbf{0.176\pi} \\
\omega_{c2} &= \frac{\omega_{s2} + \omega_{p2}}{2} = \frac{0.208\pi + 0.24\pi}{2} = \mathbf{0.224\pi}
\end{align}

\vspace{1mm}
\noindent\textbf{Step 2: Shape Parameter $\beta$ for $A_s = 60$ dB}
Since $A_s = 60 > 50$, use the top branch of \eqref{eq:kaiser_beta}:
\begin{equation}
\beta = 0.1102(A_s - 8.7) = 0.1102(60 - 8.7) = 0.1102(51.3) = \mathbf{5.653}
\end{equation}

\vspace{1mm}
\noindent\textbf{Step 3: Required Filter Length $N$}
Using \eqref{eq:kaiser_N}:
\begin{equation}
N \ge \frac{A_s - 7.95}{14.36 \cdot \Delta f} + 1 = \frac{60 - 7.95}{14.36 \times 0.016} + 1 = \frac{52.05}{0.22976} + 1 = 226.54 + 1 = 227.54
\end{equation}
Rounding up to the next odd integer:
\begin{equation}
\mathbf{N = 229} \implies \tau = \frac{229-1}{2} = \mathbf{114 \text{ samples}}
\end{equation}
Group delay in physical time: $t_d = \tau / f_s = 114 / 500 = \mathbf{0.228 \text{ seconds}}$ (constant across all frequencies).

\vspace{1mm}
\noindent\textbf{Step 4: Analytical Closed-Form of $h_d[n]$}
\begin{equation}
h_{d,\text{BS}}[n] = \begin{cases} 
1 - \frac{0.224\pi - 0.176\pi}{\pi} = 1 - 0.048 = \mathbf{0.952}, & n = 114 \\ 
\frac{\sin(0.176\pi(n - 114))}{\pi(n - 114)} - \frac{\sin(0.224\pi(n - 114))}{\pi(n - 114)}, & n \ne 114 
\end{cases}
\end{equation}
Multiplying by $w_K[n]$ synthesized with $\beta = 5.653$ yields the final $229$-tap notch filter.

\subsection{Example 23.3: Comparative Design Evaluation: Kaiser vs. Blackman Window Design}
\textbf{Problem Statement:} A telecommunications FIR channel-select filter requires a stopband attenuation of $A_s = 70$ dB with a normalized transition bandwidth $\Delta f = 0.02$.
\begin{enumerate}
    \item Determine the required filter length $N_{\text{Blck}}$ if designed using a Blackman window.
    \item Determine the required filter length $N_{\text{Kaiser}}$ and shape parameter $\beta$.
    \item Compare the design metrics (filter length $N$, group delay $\tau$, and transition width) and discuss the efficiency advantage of the Kaiser window over fixed windows.
\end{enumerate}

\vspace{1mm}
\noindent\textbf{Solution:}

\noindent\textbf{Step 1: Blackman Window Design}
A Blackman window provides a fixed peak stopband attenuation of $A_s = 74$ dB (which satisfies the $\ge 70$ dB specification). Its normalized transition bandwidth is governed by:
\begin{equation}
\Delta f \approx \frac{5.5}{N_{\text{Blck}}} \implies N_{\text{Blck}} \ge \frac{5.5}{0.02} = 275
\end{equation}
Rounding to the nearest odd integer: $\mathbf{N_{\text{Blck}} = 275 \text{ taps}}$. The corresponding group delay is:
\begin{equation}
\tau_{\text{Blck}} = \frac{N_{\text{Blck}} - 1}{2} = \frac{275 - 1}{2} = \mathbf{137 \text{ samples}}
\end{equation}

\vspace{1mm}
\noindent\textbf{Step 2: Kaiser Window Design}
For $A_s = 70$ dB:
\begin{align}
\beta &= 0.1102(70 - 8.7) = 0.1102(61.3) = \mathbf{6.755} \\
N_{\text{Kaiser}} &\ge \frac{70 - 7.95}{14.36 \times 0.02} + 1 = \frac{62.05}{0.2872} + 1 = 216.05 + 1 = 217.05 \implies \mathbf{N_{\text{Kaiser}} = 219 \text{ taps}}
\end{align}
The corresponding group delay is:
\begin{equation}
\tau_{\text{Kaiser}} = \frac{N_{\text{Kaiser}} - 1}{2} = \frac{219 - 1}{2} = \mathbf{109 \text{ samples}}
\end{equation}

Fixed windows such as Blackman have predetermined attenuation values ($74$ dB). When the user specification is $70$ dB, the fixed window forces the filter to be over-engineered, requiring $N=275$ taps. The Kaiser window, by allowing independent and continuous adjustment of $\beta$ to match $70$ dB exactly, reduces the required filter order from $274$ to $218$, saving over **$20\%$ in tap length and processing latency** while strictly satisfying the transition bandwidth requirement.

\section{6. FACULTY INSIGHTS, COMMON PITFALLS \& EXAM TRAPS}

\begin{itemize}
    \item \textbf{Pitfall 1: Truncating the $I_0(x)$ Series Incorrectly in Coding/Calculations:}
    In code or handheld calculators, students sometimes compute only 2 or 3 terms of $I_0(x)$. For large arguments ($\beta > 5$), $x^2/4$ is insufficient; one needs at least 15 terms to prevent catastrophic normalization errors in $w_K[n]$.
    
    \item \textbf{Pitfall 2: Forgetting to Enforce $\delta = \min(\delta_p, \delta_s)$:}
    In university exams, problems frequently specify $A_p = 1$ dB ($\delta_p \approx 0.057$) and $A_s = 40$ dB ($\delta_s = 0.01$). Students who calculate $N$ using $\delta_p$ rather than $\delta_s$ end up with a filter that violates the stopband specification by over 15 dB!
    
    \item \textbf{Pitfall 3: Rounding $N$ Down Instead of Up to an Odd Integer:}
    If $N_{\text{calc}} = 43.1$, students often round to 43. This causes the transition bandwidth to be slightly wider than permitted, failing specs. Always round **UP** to the next odd integer ($N = 45$).
    
    \item \textbf{Pitfall 4: Confusion between Normalized Frequency $f$ and Angular Frequency $\omega$:}
    The formula denominator $14.36 \cdot \Delta f$ requires normalized cyclic frequency $\Delta f = \Delta\omega / (2\pi)$. If a student plugs in $\Delta\omega$ directly without dividing by $2\pi$, the resulting filter length will be too small by a factor of $2\pi \approx 6.28$!
    
    \item \textbf{Pitfall 5: Assuming Kaiser Windows are Equiripple:}
    The Kaiser window produces a filter whose sidelobes decay with frequency; it is **NOT strictly equiripple** (equiripple filters are designed via the Parks-McClellan Remez exchange algorithm). However, Kaiser designs come within $1$ to $2$ dB of the theoretical Parks-McClellan lower bound on filter length.
\end{itemize}
